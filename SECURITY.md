# Security

carrot25519 is experimental, has not been audited, and is not production-ready.
Do not use it to protect production funds.

The security boundary, known limitations, and independent review questions are
documented in [AUDIT.md](AUDIT.md).

Report suspected vulnerabilities through a private GitHub security advisory.
If private reporting is unavailable, contact the repository owner privately
before disclosing details.

The project does not promise a response or remediation deadline.
